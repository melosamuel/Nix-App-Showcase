# 📱 Nix - Gestão Eleitoral

> **🏢 A project developed by [Novo Código](https://github.com/Novo-Codigo)[<sup style="color: red">1</sup>](#novo-codigo) for Infinix Tech Assessoria LTDA - 43.377.165/0001-90**

Nix is a mobile solution developed to help politicians with electoral management. The main goal was to deliver a seamless experience compared to similar apps, alongside strong security and easy navigation. For the end user, the app automates processes that were previously manual.

**🔗 Available at:** [Google Play Store](https://play.google.com/store/apps/details?id=com.gestaoeleitoral.nix) | [Apple App Store](https://apps.apple.com/br/app/gest%C3%A3o-eleitoral-nix/id6761128711)

## ⛰️ Highlights

* **Payment:** Implementation of *Apple Pay* and *Mercado Pago* with a highly secure subscription flow.
* **RBAC:** A *root* user with full privileges and *leader* roles with limited permissions
* **Security:** Single-device login policy (1 device per session) and email verification for sensitive actions.
